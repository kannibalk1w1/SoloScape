# Shared launcher settings and art — 17 October 2026

`SOLOSCAPE_LAUNCHER_HOME` optionally selects a stable launcher home outside a replaceable code tree. Its `launcher-settings.json` contains the selected port; its `launcher-art/` holds locally supplied `brazier.jpg` and `brazier-flames.png`. With the selector unset, both keep their existing locations under the current installation's `.runtime`. No settings or art is moved, created or copied by selection. Missing optional artwork keeps the existing plain-background fallback.

Set a nonempty absolute directory in `config/local.env` or the invocation environment. The graphical launcher and its Python backend validate the same path rules: relative/empty/NUL paths, files and a symbolic link at the selected directory are refused. Selection is not a defence against filesystem races or an audit of arbitrary ancestor permissions. Java validates before spawning the backend. Settings creation retains the backend's existing private directory and atomic JSON write behaviour.

Build stamps, build/world locks, runtime logs and recovery context remain version-local. Sharing those paths could let a new build mistake an older world's ownership context for its own. Profile storage and each profile's client cache retain their separate contract. This selector is preparation for managed updates, not an installer, migration, code rollback or distribution approval.

Validation uses disposable original inputs: the real Python backend writes port 43612 from one copied code root and reads unchanged settings from another, without creating either version's `.runtime`. Python tests cover invalid paths and no writes, and the actual shell launcher exports a plain local-config assignment. Four native Java path cases check defaults, cross-version selection, refusal and rendering an original green fixture through the actual `LauncherScene` using external art. Existing launcher keyboard/controller cases are included. All 215 root tooling cases pass with one optional skip; all 10 selected native Java cases pass with no skips. The 56-client/42-server patch stacks reproduce 140/87 files and the matched jars/stamp rebuild passes. [Sanitized evidence](evidence/launcher-location-20261017.json).

Physical Gaming Mode/controller/readability acceptance is still required for the eventual updated package. No owner installation, account, art or save is moved. No proprietary images or binaries are committed.
