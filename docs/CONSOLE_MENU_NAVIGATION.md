# Shared menu navigation and scrolling

The first session milestone batch connects controller-owned home tabs to their Home wheel parent. B closes an action list first; B in a native modal requests its normal close, then returns to its previous controller panel/tab when the close is observed. B at the root home tab returns to the Home wheel, preserving the highlighted tab. B in that wheel returns to world controls. Inventory opened directly keeps its direct world return; inventory opened from the wheel returns to the wheel.

Native panel focus/pane positions are remembered by native widget identity, rather than retaining old invokable actions. Reopened panels use fresh native snapshots and require neutral input before dispatch. Parent history is bounded and resets on input ownership loss. Root fixed/resized gameframe tabs remain native tabs; the hierarchy governs controller ownership rather than introducing fabricated server close operations for permanent tabs.

Right stick vertically scrolls/moves through rows in the active panel. Gentle tilt repeats slowly, strong tilt faster. In custom grids this moves focus through rows/pages; at native viewport edges it uses validated native scrolling. Opening with a held right stick requires a neutral return first. Horizontal-dominant tilt is ignored for current vertically scrollable panes. Action lists keep their D-pad selection without scrolling the underlying panel. Mouse wheel/trackpad handling remains available. Camera input is suppressed while menus own control; leaving requires right-stick neutral before panning resumes.

Tests cover Settings → graphics modal → B → Settings with restored focus → B → Home, direct versus wheel inventory ancestry, native right-stick edge scrolling without transactions, deadzone/opening neutral, speed and bounded interruption behavior. Physical menu acceptance and wider native submenus are still required. This is the foundation batch; remaining work is tracked in CONSOLE_SESSION_TASKS.md.
